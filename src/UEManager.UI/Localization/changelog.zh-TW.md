## 2.3.2 (2026-11-16)
- 「重設模組環境」現在在整個視窗中開啟，並即時記錄它涉及的每個檔案和資料夾；若因檔案正在使用而中止，日誌會指出該檔案
- 捲軸更寬，滑鼠滾輪捲動更平順；頁面的捲軸浮在邊距之上，頁面不再左右移動

- openmods：圖片檢視器以相同的 16:9 畫框顯示每張圖片，圖片比例不同時以黑邊補齊

## 2.3.1 (2026-11-15)

## 2.3.0 (2026-11-15)
- openmods：點選卡片的封面即可查看模組的封面與截圖；封面上的小框顯示圖片數量
- openmods：圖片儲存在 Data 資料夾中，頁面不再於每次啟動時下載所有封面；「設定 ▸ 清除圖片快取」可將其清空
- openmods：每張卡片上的「更新日誌」按鈕顯示每個版本的變更，內容來自該模組在 GitHub 上的發行版本
- openmods：每張卡片顯示該模組的下載次數，清單也可以依下載次數排序
- openmods：卡片更整齊，全螢幕檢視中的卡片佔滿整個寬度

## 2.2.1 (2026-11-15)
- 《明末：淵虛之羽》（實驗性）：專屬外觀、一鍵安裝 UE4SS、存檔備份，模組頁面上還有 bitfix，它的 pak 模組需要 bitfix 才能載入
- 選擇你的遊戲：「查看全部遊戲」以卡片在整個視窗中顯示所有遊戲，其中包括 Mortal Shell II（實驗性）

- 解除安裝 UE4SS 模組時會列出它寫入自身資料夾的檔案（例如記錄檔），並可將它們移到備份中（感謝 CooperZhuang）
- 模組詳細資料與「檢視檔案」中的「關閉」按鈕始終可見，檔案很多的模組也一樣

## 2.2.0 (2026-11-14)
- openmods 頁面：openmods.nexus 上為你的遊戲列出的開源模組，可搜尋、排序，一鍵安裝或更新
- openmods：模組 | 工具切換、每張卡片上的類型與類型篩選，以及「隱藏已安裝」，不顯示你已有的模組
- openmods：「全螢幕檢視」以卡片網格在整個視窗中顯示該頁面，「模組類型說明」解釋每種類型
- 在模組頁面中，從 openmods 安裝的模組以橙色連結到它在那裡的頁面，一鍵即可安裝更新
- 日文與韓文
- 帶有 .utoc 和 .ucas 檔案的 pak 模組現在也歸為 PAK；PBZModLoader 的 mods 資料夾中的模組有了自己的類型 PBZModLoader
- PBZModLoader 模組的資料檔案視為其設定：可以編輯，更新時保留，解除安裝時備份
- 設定 ▸ 系統匣圖示：「僅系統匣圖示」，不顯示工作列按鈕
- 啟動時不再閃爍：視窗繪製完成後才顯示
- 視窗與彈出框有了陰影，視窗不在前景時邊框變暗（感謝 HumanMus1c）
- 「檢視檔案」不再列出模組在自身設定檔旁寫入的設定檔（感謝 CooperZhuang）
- UEModManager.exe --cli：可在指令碼中列出、安裝、啟用、停用和解除安裝模組，備份存檔並管理 UE4SS（感謝 CooperZhuang）
- 具有模組頁面的模組，其更新檢查能正確識別 0.5.2.withHP 和 1.2a 這類版本（感謝 HumanMus1c 的回報）

## 2.1.0 (2026-11-12)
- 備份在選單中有了獨立頁面：存檔資料夾、啟動時備份和「立即備份」，備份分兩欄顯示
- 一般備份：用滑桿設定程式保留的數量，2 到 20 份（預設 6 份）；最舊的備份只會在下次備份後刪除（感謝 EstusFlask）
- 個人備份：點選綠色箭頭將備份移到這裡，程式永遠不會刪除它，它也不計入數量；紅色箭頭將它移回
- 每個備份都可以新增備註，例如「最終 Boss 之前」；「立即備份」旁也有備註欄
- 可以刪除不需要的備份，刪除前會先詢問
- 選單更緊湊，頁面標題下不再顯示說明文字；「關於」頁以版本號作為標題

## 2.0.0 (2026-11-11)
- 一個程式支援多款遊戲：《黑神話：悟空》與《影之刃零》，另有 Stellar Blade: Blood Rain，可在遊戲發售前搶先看它的外觀
- 首次啟動時或透過標題列的「切換遊戲」選擇遊戲；可在設定中設為每次啟動時提示選擇遊戲，遊戲選擇畫面還有開發者的話
- 每款遊戲都有自己的外觀、圖片和卡片；程式圖示改為模組堆疊圖示，更新後 Windows 會立即顯示新圖示
- 《黑神話：悟空》：支援 pak、UE4SS 和 C# Loader 模組，一鍵安裝 C# Loader 和 UE4SS，並支援存檔備份
- 「啟動遊戲」右側新增啟動選項：設定遊戲啟動時使用的參數，並提供該遊戲的建議參數，例如悟空的 pak 模組所需的 -fileopenlog
- 時鐘旁新增系統匣圖示，選單可切換或啟動遊戲；可在設定中讓程式最小化或關閉至系統匣
- 清單中沒有你的遊戲？在遊戲選擇畫面「掃描遊戲資料夾」，產生可在 Discord 分享的報告，你的使用者名稱和各類 ID 會被隱藏
- 遊戲選擇畫面的卡片會顯示每款遊戲在本機的位置以及已安裝的模組數量
- 首次啟動時會先詢問語言，再顯示遊戲選擇畫面，畫面中也有語言選擇
- 安裝預覽會顯示模組將安裝到哪款遊戲
- 手動放入的 UE4SS 若已是最新版本，不再提示更新
- 所有遊戲共用一個下載檔案 uemm_<version>.zip；舊版程式仍能找到更新
